#### Fichier XML

**XML** (*Extensible Markup Language*) : langage de balises extensible.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<produits>
    <produit id="1" name="HP"></produit>
    <produit id="2" name="Dell"/>
</produits>
```

- **Prologue** : `<?xml version="1.0" encoding="UTF-8"?>`

| Règle | Détail |
| --- | --- |
| Balises fermées | Toutes les balises doivent être fermées |
| Racine | Respecter l’élément racine (un seul) |
| Imbrication | Respecter l’imbrication des balises |
| Attributs | Les valeurs d’attributs sont entre guillemets doubles (`""`), même pour un entier |

#### Fichier JSON

Sans prologue.

```json
[
  {"id": 1, "produit": "HP"},
  {"id": 2, "produit": "Dell"}
]
```

|  | XML | JSON |
| --- | --- | --- |
| **Prologue** | Oui (`<?xml ... ?>`) | Non |
| **Structure** | Balises et attributs | Objets, clés/valeurs, tableaux |
| **Usage** | Échange de données entre applications | Échange de données entre applications |

#### Comment connecter des systèmes d’information distribués ?

|  | Communication synchrone | Communication asynchrone |
| --- | --- | --- |
| **Principe** | Une application pose la question à une autre et **attend la réponse** | Une application pose la question à une autre et **continue son travail** |
| **Fin de l’attente** | Si l’autre ne répond pas, elle se bloque | Elle reçoit une **notification** lorsque la réponse arrive |
| **Outils** | — | **BROKER** : Kafka, RabbitMQ |
| **Formats d’échange** | XML, JSON | XML, JSON |

#### Web Service

Pour la communication entre deux applications (APP1, APP2), on a besoin d’un canal : le **WEB SERVICE**.

```
APP1  <──── WEB SERVICE (SOAP / REST) ────>  APP2
```

> **Un web service (ou service web)** est un programme informatique qui permet à différentes applications de communiquer et d’échanger des données entre elles à travers Internet, indépendamment de leur langage de programmation ou de leur système d’exploitation.

| Style | Remarque |
| --- | --- |
| **SOAP** | Web service basé sur SOAP |
| **REST** | Web service basé sur REST |

#### AI Agent

```
AI AGENT (LLM + outils)  <──── MCP ────>  Serveur Backend
```

Un **AI Agent** utilise un **LLM** (*Large Language Model*) avec des outils, et communique avec le serveur Backend via le protocole **MCP**.

## 4. Exemple d’un fichier XML

```xml
<?xml version="1.0" encoding="UTF-8"?>
<biblio>
    <etudiant code="1" nom="A" prenom="B" age="23">
        <livre id="534" titre="java" datepret="2006-11-12"/>
    </etudiant>
    <etudiant>
        <livre id="233" titre="E-commerce" datepret="2006-12-11"/>
    </etudiant>
</biblio>
```

Arborescence :

```
                        biblio
          ┌────────────────┼────────────────┐
      etudiant          etudiant        etudiant
          │                 │               │
    livre   livre      livre livre         ...
```

## 5. Document XML

Un document XML se compose de trois parties :

| Partie | Fichier / langage |
| --- | --- |
| **Données** | `.xml` |
| **Structure des données** | `DTD, XSD` |
| **Mise en forme** |` XSL` |

**Structure d'un document XML**
---
Un docuemnt XML se compose de 3 fichiers:

| Document | XML |
| --- | --- |
| **Fichier XML** | `Qui contient les donnees` |
| **DTD** | `Schemas XML pour declarer la structure du fichier XML` |
| **Feuille de style XSL** |` Pour la presentation des donnees du fichier XML   ` |
